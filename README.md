# Personal Expense Tracker

A command-line expense management tool designed to record, categorize, and summarize personal spending.

## Features

- Add and categorize personal expenses
- Automatically record the date of each expense
- View expense history
- Delete existing expenses
- Calculate total spending
- Store expense data in CSV format
- Validate user input for expense amounts

## Technologies

- Python
- CSV
- Git
